# GB Imports | Flagship V05

Protótipo navegável da **GB Imports**, desenvolvido pela **SET77 LABS**.

**Link de produção:** https://gb-imports-set77.vercel.app  
**Plataforma:** Vercel com integração GitHub (branch `main`).

## Estrutura deste repositório
- `index.html`: preview independente com UI, CSS, JS e ativos incorporados.
- `vercel.json`: configuração de hospedagem e cabeçalhos de segurança.
- `CLAUDE.md`: instruções públicas para continuidade no Claude Code.
- `robots.txt`: ambiente de demonstração fora da indexação.

## Executar e evoluir
Abra `index.html` no navegador ou rode um servidor estático local.
Faça alterações em uma branch, valide a experiência em desktop e mobile e integre pela branch `main` para deploy automático.

> **Atenção:** este repositório está **público** e contém apenas o código da experiência demonstrativa. O arquivo ZIP V05 com skills, vídeos de referências, manuais e documentos internos permanece fora do GitHub por segurança. Faça a gestão desse material na pasta local privada.

### Limitações do protótipo
As fotos oficiais de todos os produtos, informações comerciais validadas, estoque, pagamentos, CRM e checkout real ainda não foram integrados. A identidade V1 é uma proposta sujeita à aprovação da GB. Não use a demonstração para receber compras reais.
